# Zusätzliches Bildmaterial

Dieser Ordner sammelt zusätzlich bereitgestellte Bildquellen für den Website-Relaunch und gilt für alle Theme-Varianten.

- Originaldateien möglichst unverändert ablegen.
- Aussagekräftige Dateinamen verwenden.
- Optimierte und von Hugo erzeugte Varianten gehören nicht hierher.
- Vor der Veröffentlichung Nutzungsrechte und Bildinhalt prüfen.
